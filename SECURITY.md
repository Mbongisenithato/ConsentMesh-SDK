# Security Policy

## Supported Versions

ConsentMesh Pro actively provides security updates, cryptographic integrity checks, and dependency patches for the current stable release line.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The security of ConsentMesh Pro, user data privacy, and consent orchestration pipelines is a top priority. If you discover a vulnerability affecting our consent workflows, cryptographic modules, or API endpoints, please disclose it responsibly.

**Reporting Channels & Process**
* **Private Disclosure:** Do not open public GitHub issues for security vulnerabilities. Use GitHub's built-in private vulnerability reporting tab or reach out directly to the repository maintainer.
* **Information to Include:** Provide a clear description of the vulnerability, step-by-step reproduction instructions, affected components (e.g., Next.js app routes, DynamoDB schemas, or telemetry handlers), and potential impact.
* **Response Timeline:** Expect an initial acknowledgment within 48 hours, with a comprehensive status evaluation provided within 5 business days.
* **Resolution Workflow:** Validated security flaws receive rapid patching, coordinated testing, and a security advisory release. Reporters who adhere to responsible disclosure guidelines receive formal acknowledgment in our release notes.
